# EPCW Interactive updates

## Latest: version 2.1.7

[Download the 2.1.7 installer](https://raw.githubusercontent.com/goncalvesmathias123-art/mc-stuff/v2.1.7/installers/EPCW-Interactive-2.1.7-Setup.exe).

Use **Check for updates → Download → Restart & install**. Close both games before installation. Older-host launchers require one manual migration installation.

The monster now aims to reach you about 0.7 seconds after water contact. Clear-water tests catch stationary, hopping and sprinting-away players in 0.70–0.72 seconds. Moving into its body can cause earlier contact; blocked paths and pillars can delay arrival. It stops against the player during the grab, and genuine dry landings still end pursuit.

The interface follows the supplied pause-screen reference: pale serif lettering, a centered PAUSED heading and level readout, and borderless Resume / Restart Level / Settings / Quit options over a dimmed full-screen room. The HUD title reads DON'T TOUCH THE WATER. Settings retain volume, sensitivity, shadows and fullscreen controls with Back/Escape navigation.

Keeps all 100 levels with 50 jumps each, the screen-filling aspect fix, tiled Poolrooms, round pillars, large four-legged creature, crows, wide gaps, saves and two-second full-screen catch static. Original Parkour Paridise 2 and launcher controls/mappings remain.

Validation: 6,751 core checks, timed contact/hopping/running tests, actual Poolrooms pursuit, rendered pause/settings interaction tests, widescreen/ultrawide/4:3 checks, 15 launcher tests, browser controls and exported-game integration. Course geometry is unchanged from the prior 5,000-jump/100-tunnel traversal. Native Windows execution and human balancing remain untested.

Updates retain the existing signing key. The launcher verifies the manifest signature, installer size and SHA-256 before installation. No private signing key or user data is published. Liberation Serif is redistributed with its SIL Open Font License.
