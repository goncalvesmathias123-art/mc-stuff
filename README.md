# EPCW Interactive updates

## Latest: version 2.1.5

[Download the 2.1.5 installer](https://raw.githubusercontent.com/goncalvesmathias123-art/mc-stuff/v2.1.5/installers/EPCW-Interactive-2.1.5-Setup.exe).

Use **Check for updates → Download → Restart & install**. Close both games before installation. Older-host launchers require one manual migration installation.

The monster now pursues at a steady speed capped at 9.5 m/s, with gradual acceleration. Water still alerts it immediately, while reaching real dry ground ends pursuit. Jumping repeatedly in water does not cancel the alert, and attacks stop at body contact without passing through the player.

The rendered view expands to fill the screen instead of adding black side bars. Verified at 16:9, ultrawide and 4:3 sizes.

Keeps the tiled Poolrooms and tall round pillars, 100 levels with 50 jumps each, mixed-size wide-gap routes, large four-legged creature, flying crows, top-centre HUD, two-second catch static, saves and tunnels. Parkour Paridise 2 and original launcher mappings/TikFinity/overlay controls remain.

Validation: 6,751 core checks, slower stationary and moving/hopping contact tests, real-room chase and column navigation, close swimming, rendered aspect-ratio checks, 15 launcher tests, browser controls and actual exported-game integration. The unchanged routes previously passed all 5,000 actual jumps and 100 tunnels. Native Windows execution and human balancing remain untested.

Updates use the existing signing key. The launcher verifies manifest signature, installer size and SHA-256 before installation. No private signing key or user data is published.
