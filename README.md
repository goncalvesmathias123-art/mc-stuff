# EPCW Interactive 2.2.22

Minecraft Chat Chunk now includes a searchable, paginated library of all 1198 supported block names and IDs. Each block has an on/off switch, saved immediately. Disabled-only filtering, Enable all, Disable all, and a downloadable full list are available. All blocks initially remain enabled; existing disable choices are preserved across restarts.

Disabled blocks are rejected from TikFinity chat, aliases, manual play tests, and queued requests before dispatch. For example, disabling diamond_block also blocks diamond and diamond block. The block settings belong to Chat Chunk and do not change gift profiles for the other games.

Close both games -> Check for updates -> Download -> Restart & install. Open Minecraft Chat Chunk -> Chat Block Library, search for a block and uncheck it to disable it.

Validation: all 19 launcher tests passed. Seven packaged chat and updater tests passed. Tests cover disabled aliases, play tests, queued cancellation, bulk toggles, atomic invalid-input rejection, export and restart persistence. Browser preview verified the saved checkbox state. Staged upgrades from 2.2.20 and 2.2.21 passed. Game PCK, Minecraft bridge and centered SAVE overlay are unchanged. Real LIVE reception remains unverified.
