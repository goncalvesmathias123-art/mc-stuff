# EPCW Interactive updates

## Latest: version 2.1.6

[Download the 2.1.6 installer](https://raw.githubusercontent.com/goncalvesmathias123-art/mc-stuff/v2.1.6/installers/EPCW-Interactive-2.1.6-Setup.exe).

Use **Check for updates → Download → Restart & install**. Close both games before installation. Older-host launchers require one manual migration installation.

The monster now aims to reach you about 1.2 seconds after water contact. Its pursuit speed adapts to distance, route length and player movement. Clear-water tests reach stationary, hopping and sprinting-away players in 1.20–1.22 seconds. Moving into its body can cause earlier contact; pillars and blocked paths can delay arrival.

It still stops against you during the grab. Water jumping keeps pursuit active, while genuine dry landings end it. The two-second full-screen catch static remains unchanged.

The screen-filling fix from 2.1.5 remains, along with the tiled Poolrooms, round pillars, large four-legged creature, crows, 100 levels with 50 jumps each, wide gaps, saves and top-centre HUD. Original Parkour Paridise 2 and launcher controls/mappings remain.

Validation: 6,751 core checks, timed contact/hopping/running tests, actual Poolrooms pursuit and pillar navigation, 15 launcher tests, browser controls and exported-game integration. Course geometry is unchanged from the prior 5,000-jump/100-tunnel traversal. Native Windows execution and human balancing remain untested.

Updates retain the existing signing key. The launcher verifies the manifest signature, installer size and SHA-256 before installation. No private signing key or user data is published.
